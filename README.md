# MAP-Housing-ATO-Calculator-Updated

This repository contains the code to generate data for the https://wfrc.org/housing-ato-calculator-map/.

This repository is an attempt to recalculating Housing Access-to-Opportunities from scratch using R, DuckDB, and GeoParquet for efficiency. Refer to the original repository at: [MAP-Housing-ATO-Calculator](https://github.com/WFRCAnalytics/MAP-Housing-ATO-Calculator/)

The web application itself can be found in the _site folder.
